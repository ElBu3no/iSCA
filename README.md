Framework de reconhecimento automatizado para descoberta de superfície de ataque, coleta de endpoints, análise de parâmetros e identificação inicial de vulnerabilidades em aplicações web.  Projetado para Bug Bounty, Pentest e Pesquisa em Segurança Ofensiva.
